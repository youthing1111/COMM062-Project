# COMM062-Project

An improvement in Particle Swarm Optimisation (PSO) in finding the best weights and bias value for recurrent neural networks that I implemented in my Computer Intelligence module. Compared to the default PSO, my version has:
- An encoding scheme inspired by an Internet Protocol address that makes it efficient to encode weights
- A function to grow the population size to improve the efficiency of the algorithms
- A suitable mechanic for handling the boundary requirement of the encoding scheme
